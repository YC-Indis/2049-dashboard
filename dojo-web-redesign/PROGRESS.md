# 当前进度与真实验证

记录以本机 2049 工作台为准，不是设想。

## 已验证

- 本地端：`http://127.0.0.1:5191/`，首页会落到项目管理。
- 检索曾把 `xros` 等品牌词和项目名拼进查询。已改成只搜用户写下的独立词；敏感词不会改写成品牌包。
- 对标库已从列表改成卡片。收藏写入本机对标库，可标类目和脚本方向。
- 灵感库可从当前视频账号点「打开主页」，把账号加入对标库。
- Agent 写操作走确认流：复述后等「确认」才执行，「取消」停下。
- 对话和待确认工作流写入本机长期存储，翻页、收起、刷新后还在。
- 椭圆按钮和对话框都能拖，位置写入本机。
- Agent 写操作按项目名定位。项目多于 1 个且没点名时先问，不默认写进当前选中项。
- 增删改查已覆盖项目、任务、采集、灵感、脚本、对标账号，以及账号同步和运营查询。
