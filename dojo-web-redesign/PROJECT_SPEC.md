# 2049 中台业务范围

2049 是内容生产中台，不是某一个品牌的专属后台。SixNine49 是中台里的工作助手，必须跟着「任意数量的项目」工作。

## 固定范围

- 执行：项目管理、时间规划、执行日历
- 内容：灵感采集、灵感库、对标库、脚本制作
- 运营：运营驾驶舱、账号矩阵、视频监控、工作复盘

## 项目模型

- 一个客户/市场/产品周期 = 一个项目。
- 项目可以持续增加，不设数量上限。
- 项目之间的 KPI、排期、账号、灵感、脚本必须能分开查、分开改。
- 当前选中项目只影响界面默认焦点，不限制 Agent 能看见或操作的项目集合。

## 明确不做

- 不把某个品牌词写进检索、分类或默认采集。
- 不把 TikTok 收藏当成自己的收藏。对标库收藏只存在本机。
- 不在用户没点名时，把写操作落到「手头那个项目」。
- 不把本地规划线索拿去当线上检索词。

## Agent 能力边界

前端改数据，模型只理解意图。SixNine49 可以：

- 增加：项目、任务、采集线索、灵感、脚本、对标账号
- 修改：项目信息、环节日期、现状数字、灵感/脚本字段、对标分层
- 删除：项目、任务/时间条、灵感、脚本、采集线索、对标账号
- 查询：项目清单与进度、采集结果、灵感库、脚本、对标库、账号运营

采集关键词必须来自用户，不能由项目名或品牌名补全。
