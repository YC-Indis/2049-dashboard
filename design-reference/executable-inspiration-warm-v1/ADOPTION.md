# 参考落地说明

这是一份未来应用这套视觉时使用的清单，不是本次要执行的改造任务。

## 应用边界

允许改变：

- CSS 变量与 Element Plus 主题映射。
- 侧栏、顶栏、页面背景、字体层级、圆角与阴影。
- 页面内部的视觉分栏和响应式折叠方式。
- 按钮、输入、状态、候选行、索引项和功能面板的视觉表现。

禁止顺带改变：

- route path、导航分组和导航文案。
- store 结构、类型、字段名、storage key 和 API contract。
- 当前项目选择、写操作确认和独立检索词规则。
- Candidate、Executable Inspiration、Script、CreatorContent 的对象边界。
- 真实 provider 配置与 AI 证据门槛。

## 建议顺序

### 先做视觉开关

- 将 `tokens.css` 作为可选主题接入，不覆盖默认 `:root`。
- 只在 `data-dojo-theme="warm-editorial"` 存在时启用。
- 保留当前主题作为回退，便于逐页比较。

### 再换壳层

- 侧栏切为深紫材质，保留当前收纳、搜索、分组和移动抽屉逻辑。
- 顶栏切为暖纸表面，保留当前项目上下文、命令入口和导航行为。
- 不恢复旧 `creator-os` 品牌、目标卡、头像或吉祥物。

### 再换基础组件

- Element Plus 颜色、输入、按钮、对话框、标签和 focus ring。
- 原生 `.dojo-action-row`、`.dojo-chip-row` 与页面 panel。
- 图标库和组件 API 不变。

### 最后逐页调整版式

1. 灵感采集。
2. 灵感库。
3. 脚本制作。
4. 执行日历和时间规划。
5. 项目与运营页面。

每一页只改视觉与布局，不在同一批次改业务状态。

| `--dojo-canvas` | `--warm-canvas` |

| `--dojo-ink` | `--warm-ink` |

## 视觉验收

- [ ] 当前所有 route path 和导航标签未变化。
- [ ] 页面背景统一为暖纸色，没有局部冷银蓝残留。
- [ ] 侧栏是唯一持久深色大面。
- [ ] 珊瑚红只表示人类主操作或当前选择。
- [ ] 紫色只表示 AI、转化或稳定选择状态。
- [ ] 一个视口最多一个珊瑚紫渐变按钮。
- [ ] 候选、脚本和账号长列表没有被改成卡片墙。
- [ ] 宋体只出现在页面方向和内容标题。
- [ ] 输入、按钮和图标触摸目标不小于 40px。
- [ ] loading、empty、error、awaiting-provider 都有独立表达。
- [ ] 桌面、800px 和 390px 三类视口无整页水平滚动。
- [ ] 键盘焦点、抽屉焦点返回和 reduced motion 正常。
- [ ] 所有写操作与删除确认逻辑保持原样。
- [ ] 真实 URL、来源账号、项目 ID 与对象关联不丢失。

## 明确不是验收项

- 不要求旧版页面逐像素复刻。
- 不要求恢复旧版演示数据。
- 不要求本次就启用这套主题。
- 不把附件 v1 中未实现的功能视为视觉缺陷。
