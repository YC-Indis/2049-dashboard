# 页面版式

本文件描述视觉参考中的页面骨架。它不要求当前项目立即采用，也不改变现有 route path 或页面职责。

## 全局壳层

### 桌面端，1280px 及以上

```text
┌────────────── 288px ──────────────┬────────────────────────────────────────┐
│ 深紫侧栏                          │ 88px 暖纸顶栏                           │
│ 2049                              ├────────────────────────────────────────┤
│ 搜索                              │                                        │
│ 执行                              │ 页面标题与当前任务                     │
│ 内容                              │                                        │
│ 运营                              │ 任务专属工作区                         │
│                                  │ 最大宽 1620px                          │
│ 工作复盘 / 设置                   │                                        │
└───────────────────────────────────┴────────────────────────────────────────┘
```

- 侧栏固定，展开宽 288px，收纳宽 72px。
- 顶栏固定在工作区顶部，高 88px。
- 页面内容最大宽 1620px，水平内边距 48px，垂直内边距 42px / 54px。
- 侧栏是唯一大面积深色区域。页面内容不再局部切换成冷蓝深色主题。
- 当前导航分组“执行、内容、运营”保持不变。

### 中等宽度，801-1279px

- 默认收纳侧栏至 72px，用户可展开。
- 页边距降至 24-32px。
- 三栏工作区优先变成“主工作区 + 可打开的右侧抽屉”。
- 搜索、筛选和主操作允许换行，但主操作保持一行文字。

### 移动端，800px 以下

- 侧栏变成抽屉，页面本体不为侧栏预留宽度。
- 顶栏降至 64px，只保留菜单、页面名称和最关键动作。
- 页面边距为 14-18px，标题为 28-34px。
- 所有分栏按任务顺序变为单列。
- 日历、时间轴等固定格式内容只允许在自身容器内横向滚动。
- 弹窗宽度使用 `calc(100vw - 32px)`，底部操作在需要时固定。

## 页面标题

顶层页面采用编辑式标题，但标题区不占满首屏。

```text
[可选的短标签]
一句明确的页面方向。
一行说明当前在这里完成什么。
                                      [上下文操作]
```

- 每页一个主标题，桌面最多两行。
- 标签不是必须项。一个页面中不重复堆叠全大写标签。
- 说明文字不超过 72 个中文字符。
- 标题区与主工作区间距 24-34px。
- 筛选和创建操作若与内容高度相关，放入工作区工具栏，不堆在标题右侧。

## 灵感采集

### 信息结构

```text
搜索 | 热门榜单 | 对标库

┌──────── 320-360px ────────┬──────────────────────────────────────────┐
│ 灵感线索                   │ 候选批次                                 │
│ 新建 / 编辑 / 启停         │ 批次摘要、状态、采集时间                 │
│ 平台、独立检索词           ├──────────────────────────────────────────┤
│ 时间窗、排序、数量         │ 候选行                                   │
│ 运行采集                   │ 指标、摘要、预览、忽略、晋升             │
│ 最近任务                   │                                          │
└────────────────────────────┴──────────────────────────────────────────┘
```

- 模式切换使用紧凑分段控件，当前项为深紫实色。
- 左侧控制台固定宽度，不随候选结果多少跳动。
- 候选用行，不用三列卡片。每行保持指标对齐。
- 首个批次默认展开，其余批次可折叠。
- 候选预览使用抽屉或对话框，不挤压结果列。
- provider 未配置、无结果、过滤后为 0、采集失败是四种不同状态。

### 候选行栅格

桌面建议：`72px minmax(280px, 1fr) 220px 120px`。

1. 热度 / 新鲜度摘要。
2. 来源、作者、日期、标题、摘要、标签。
3. 播放、点赞、评论、收藏或可用子指标。
4. 预览、忽略、晋升操作。

在 980px 以下，指标移到标题下方，操作保持在行底部；在 640px 以下，一条候选占一个完整内容块。

## 可执行灵感库

### 信息结构

```text
┌──────── 300-340px ────────┬──────────────────────────────────────────┐
│ 灵感知识库                 │ 可执行灵感详情                           │
│ 数量、AI 导入、添加        │ 标题、角度、来源、类目、标签             │
│ 搜索                       │ 记录启发、编辑、生成脚本                 │
│ 时间 / 类目 / 标签分层     ├──────────────────────────────────────────┤
│ 条目列表                   │ 视频预览 + 文字证据编辑                  │
│                            │ Hook                                     │
│                            │ 镜头 / 话术 / 音乐建议                   │
│                            │ 改编需求与批注                           │
└────────────────────────────┴──────────────────────────────────────────┘
```

- 左侧索引是安静的纸色区域，选中项用暖珊瑚底色和深色文字。
- 详情标题允许使用宋体，其余信息保持无衬线。
- 视频预览与证据编辑在宽屏按 5:7 排列。
- 镜头、话术、音乐是三个真实工作对象，可以使用三个功能分区，但避免相同 KPI 卡样式。
- 证据完整度靠文字和图标共同表达，不能只靠颜色。
- 详情区域内部不再嵌套额外的大圆角总卡。

## 脚本制作

### 信息结构

```text
┌──── 280-320px ────┬──────────────────────────────┬──── 340-380px ────┐
│ 脚本索引           │ 脚本编辑器                   │ AI 拆解台          │
│ 搜索与分层         │ 来源、状态、标题             │ 当前上下文          │
│ 草稿 / 已确认      │ 正文、类目、标签             │ 快速提示            │
│ 已进入执行         │ 保存、确认、进入项目         │ 对话与写回          │
└────────────────────┴──────────────────────────────┴────────────────────┘
```

- AI 面板使用深紫的浅层变体或紫色强调，不使用冷蓝背景。
- 编辑器是最亮、最稳定的纸面。
- 1280px 以下 AI 面板变为右侧抽屉。
- 980px 以下脚本索引变成页内选择器或左侧抽屉。
- “确认入库”和“进入执行日历”是连续门槛，不能视觉上同时作为两个主按钮。

## 执行日历

```text
┌──────── 330px ────────────┬──────────────────────────────────────────┐
│ 待安排池                   │ 周 / 月日历                              │
│ 固定工作                   │ 日期导航、今天、新增                     │
│ 内容阶段任务               │ 事件、阶段、负责人                       │
│ 拖动提示                   │ 拖放与改期                               │
└────────────────────────────┴──────────────────────────────────────────┘
```

- 左栏使用略深的暖纸色，日历使用强纸色。
- 阶段色只作为 3px 左边标或小面积图标底色。
- 今日使用浅珊瑚底和珊瑚日期，不使用大面积纯色。
- 拖动对象获得轻阴影与 1px 上移，目标日期使用清晰边框。
- 移动端默认展示周视图和待安排抽屉，不强塞完整月视图。

## 运营与数据页面

- 暖色化不意味着取消数据密度。
- 图表背景保持纸色，坐标和网格使用暖灰线。
- 珊瑚红用于当前选择或用户动作，不默认作为全部数据系列颜色。
- 多数据系列优先使用蓝、绿、琥珀等低饱和阶段色。
- 指标必须能下钻、筛选或创建行动，否则并入正文摘要。
- 不建立四张或更多相同 KPI 卡组成的首屏。
