# 组件规范

组件沿用当前 Vue、Element Plus 与 Iconify 技术栈。本文件只定义外观和可见行为。

## 组件层级

| 层级 | 组件 | 视觉重点 |
| --- | --- | --- |
| 壳层 | Sidebar, Topbar, PageHeader | 深紫结构、暖纸页面、编辑式标题 |
| 导航 | NavItem, Tabs, SegmentedControl | 当前状态清晰，不靠装饰点 |
| 操作 | Button, IconButton, Menu | 珊瑚红人类动作，紫色 AI 动作 |
| 输入 | Input, Select, Textarea, Search | 强纸色、暖灰边、紫色焦点环 |
| 内容 | CandidateRow, IndexItem, DetailSection | 行式扫描、少量功能分区 |
| 状态 | Badge, Notice, Skeleton, EmptyState | 文字、图标、颜色三者协同 |
| 浮层 | Drawer, Dialog, Popover, Toast | 紫灰阴影、明确确认与取消 |

## 按钮

### Primary

- 用途：保存、晋升、安排、确认等当前页面的主要人类动作。
- 高度：42px，紧凑版 32px。
- 水平内边距：18px，图标间距 8px。
- 背景：`action-coral`。
- 文本：`paper-strong`，至少达到 WCAG AA。
- hover：背景变为 `#c95750`，上移 1px。
- active：回到原位或下移 1px。
- focus：3px 紫色透明外环。

### Create / Promote Gradient

- 仅用于全局新建或 Candidate 晋升为 Executable Inspiration。
- 渐变：`action-coral -> #c75f8c -> ai-purple`。
- 一个视口最多出现一个，不能作为所有主按钮默认样式。

### AI

- 背景：`ai-purple-deep`。
- 文案必须描述具体结果，例如“AI 快速检查”“拆解并转化”“写入转化稿”。
- 不使用只写“AI”的模糊按钮。
- AI 未配置时显示可操作的 provider 状态，不伪装成功。

### Secondary

- 背景：`paper-strong`。
- 边框：`line-strong`。
- 文本：`ink` 或 `ink-secondary`。
- hover：`paper-tint`。

### Destructive

- 默认使用图标按钮或低强调文字按钮。
- 删除必须有明确对象名的确认对话框。
- 与 Primary 并列时放在操作组末尾并拉开间距。

### Disabled 与门槛未满足

- `disabled` 表示动作当前不可触发。
- “尚未满足业务门槛”优先使用可解释的非主态按钮，保留 tooltip 或邻近原因。
- 不允许只降低透明度，让用户猜测缺什么。

## 图标按钮

- 使用项目已有 Iconify 图标，保持同一 Phosphor 系列。
- 尺寸：16-20px；触摸目标不小于 40px。
- 常见图标操作提供 `aria-label`、`title` 或 tooltip。
- 删除、关闭、前后切换、侧栏收纳等熟悉动作优先只用图标。

## 输入控件

- 高度：42px，搜索框可为 40px。
- 圆角：10px。
- 背景：`paper-strong`。
- 边框：`line-strong` 1px。
- focus：紫色 1px 内描边 + 3px 外环。
- placeholder 颜色不得低于 `#8e858b`。
- 长文本字段使用明确标签、字数或证据说明，不把说明全塞进 placeholder。
- 表单错误显示在字段下方，toast 只负责操作结果。

## 导航项

- 桌面高度：46px，圆角 12px。
- 默认文字：68% 白。
- hover：5% 白叠层。
- active：`sidebar-plum-active` + 3px 珊瑚左边标。
- 分组名 11px，字距保持正常，不使用夸张全大写。
- 收纳态居中图标，并显示 tooltip。

## 分段控件与页内标签

- 外壳使用强纸色和暖灰边。
- 当前项用 `ai-purple-deep`，文字为白色。
- 用于“周 / 月”“搜索 / 热门榜单 / 对标库”等互斥视图。
- 不用于普通命令，命令必须使用按钮。

## 候选行

### 必须展示

- 平台、作者、发布时间。
- 标题与摘要。
- 热度、新鲜度和可用的真实表现子指标。
- 当前状态。
- 预览、忽略、晋升。

### 版式

- 行间使用底部分割线，不给每行完整卡片阴影。
- hover 使用 `paper-tint` 或极浅珊瑚底。
- 标题 15-16px，摘要 12-13px，元数据 11px。
- 标签最多首显 4 个，其余用数量表示。
- 指标缺失时写“待接口回填”，不显示假 0。

## 分层索引项

- 时间、类目、标签是三种分组方式，选择器固定在索引顶部。
- 条目主标题一行，副标题最多一行。
- 选中项使用浅珊瑚背景、加深文字和 3px 珊瑚边标。
- 数量徽标只显示真实条数。
- 空分组不渲染。

## 详情区

- 详情区本身不放在额外外层卡片内。
- 标题、来源、状态和主操作组成一个清晰 header。
- 功能分区使用 18px 圆角和暖灰边。
- 长列表使用编号步骤、结构化字段或可折叠章节。
- 来源 URL 永久保留，并明确是否可站内预览。

## 证据编辑器

- 两个必填概念：字幕 / 口播文本、画面证据笔记。
- 宽屏并列，窄屏垂直排列。
- 完整度显示“证据完整”或“待补 2 项”，不能只用绿 / 灰颜色。
- 保存证据与生成脚本是两个不同动作。
- AI 未读取视频时，界面必须清楚写明它基于文字证据工作。

## 状态标签

| 语义 | 颜色 | 示例 |
| --- | --- | --- |
| 新建 / 待处理 | 暖灰 | new, queued |
| 处理中 | 低饱和蓝 | running |
| 可执行 / 完成 | 低饱和绿 | qualified, completed |
| AI / 转化 | 紫色 | ai-adapted |
| 等待配置 | 琥珀 | awaiting-provider |
| 忽略 / 拒绝 | 暖灰或低饱和红 | rejected |
| 已晋升 | 珊瑚 | promoted |
| 失败 | 低饱和红 | failed |

状态标签使用 8px 圆角，不默认使用全胶囊。颜色必须配合可读文字。

## 面板与卡片

- 标准功能面：18px 圆角，16-24px 内边距。
- 大型复合工作区：24px 圆角，但只在最外层使用一次。
- 嵌套分区优先用色差、标题和分隔线，不再套一层同样的卡片。
- 阴影只用于浮层、拖动态和真正独立的重点面板。

## 对话框与抽屉

- 对话框用于确认、短表单和有明确结束点的编辑。
- 抽屉用于预览、复杂详情和中等宽度下的第三栏。
- 标题必须包含对象名或动作结果。
- 删除确认必须说明关联对象是否保留。
- 主操作在右，取消在左；危险操作不使用珊瑚紫渐变。

## Loading、Empty、Error

### Loading

- 使用与最终行、详情和编辑器形状相同的骨架。
- 采集任务必须同时显示状态文字，不能只有转圈。

### Empty

- 说明为什么为空。
- 给出一个最合理的下一步，例如“新建线索”“调整独立检索词”“添加灵感”。
- 不放装饰性插画占据大面积。

### Error

- 区分 provider 未配置、网络失败、过滤后为空、权限未确认和字段错误。
- 保留用户已经输入的内容。
- 提供重试、修改条件或返回上一层的明确动作。

## 动效

- 默认 140-200ms，使用 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 只动画 `transform`、`opacity` 和颜色。
- 拖放、抽屉、分段切换和操作结果可以有动效。
- 不使用自动轮播、无限悬浮、背景粒子或滚动劫持。
- `prefers-reduced-motion` 下变为即时状态切换。
