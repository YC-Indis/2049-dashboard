# SixNine49 协作与测试规则

这份文件给人和 Agent 共用。改工作台之前先读，不要靠当前打开的那一两个项目猜全局规则。

## 协作

- 写操作必须先复述将改的对象和字段，等用户确认后再执行。取消就停。
- 拿不准是「新建项目」还是「在某项目下建任务」时，先问，不要猜。
- 检索只打用户给出的独立词。禁止把当前项目名、品牌名或竞品品牌自动拼进查询。
- 中台会同时对接很多项目。当前选中项目只是上下文提示，不是唯一工作对象。
- 项目级写操作必须带上项目名称或别名。多个项目且用户没点名时，先列出候选再问要改哪一个。
- 不要把演示数据、某个品牌或某次活动写成系统默认值。

## 能改什么

Agent 可以对工作台里的真实记录做增加、修改、删除、查询，范围包括：

- 执行：项目、任务、环节日期、现状数字
- 内容：采集线索、灵感库（含口播改稿）、对标库账号与本地收藏
- 运营：账号同步、账号查询、停滞/播放查询

查询可以直接答。增加、修改、删除先确认。

## 测试

验证时至少覆盖这些，不要只拿现有两三个项目当全集：

1. 新建一个与当前选中项目无关的新项目，再对它改期、建任务、改现状。
2. 不点名项目时，Agent 必须追问，不能默默写进当前选中项。
3. 检索 `unboxing` 这类独立词时，实际检索词不能出现项目品牌。
4. 翻页、收起再打开悬浮窗后，对话和待确认动作还在。
5. 椭圆形按钮和对话框都能拖走，刷新后位置还在。
6. 对标库收藏只进本机库，不写回 TikTok。
